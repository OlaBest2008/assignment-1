## system-info.sh
This bash script conntains the hostname, current user, date/time, operating system, kernel version, uptime, CPU information, memory information and current working directory.

## disk-check.sh
Monitors disk usage percentage for a specified path against a threshold percentage (1–100).

## network-check.sh
Resolves hostnames to IP addresses, performs ICMP ping connectivity checks, displays active network interface details, and optionally verifies TCP port connectivity.
